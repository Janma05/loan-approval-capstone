# Loan Approval Analysis Dashboard

## Project Overview
This is a CA4 Business Analytics capstone project.
It uses Python, Pandas, Plotly, and Streamlit to explore
loan application data and compare loan status patterns.

## Business Objectives
- Examine the distribution of loan application statuses.
- Compare patterns by occupation and loan purpose.
- Explore relationships with credit scores and financial variables.
- Present results through an interactive dashboard.

## Technologies
- Python
- Pandas
- Plotly
- Streamlit
- Google Colab
- GitHub

## Run Locally
Install dependencies:

pip install -r requirements.txt

Run the dashboard:

streamlit run app.py

Upload the CSV dataset using the dashboard uploader.

## Important Note
The meaning of loan_status values 0 and 1 must be verified
from the original dataset documentation before describing
them as rejected or approved applications.
All conclusions must be supported by the actual data.
